## Methodology

The development process was collaborative:

1. **Human** defined the problem, selected the dataset, and set quality targets (beat paper baseline WAPE 27.62%).
2. **AI** implemented code drafts based on human specifications.
3. **Human** reviewed all outputs, ran experiments on Kaggle/Lightning AI, and interpreted results.
4. **Human** identified the data leakage bug (recovery features in FEATURE_COLS) by analyzing SHAP importance.
5. **AI** helped fix the bug and restructure the pipeline.
6. **Human** made all final decisions on model architecture and which results to report.

All experimental results reported in the benchmark are from actual training runs, not simulated or cherry-picked.
